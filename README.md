# Análise de Gerenciamento de Memória no Windows

**Projeto acadêmico — Administração de Sistemas Operacionais**

## 📌 Sobre o projeto

Este projeto apresenta uma análise prática do gerenciamento de memória no sistema operacional Windows.

O experimento teve como objetivo observar o comportamento da memória antes e depois do aumento da carga de trabalho, analisando o consumo de RAM, memória confirmada, processos com maior utilização de memória e o comportamento geral do sistema.

A atividade foi realizada como parte da disciplina de **Administração de Sistemas Operacionais**, dentro do conteúdo de gerenciamento de memória, alocação e memória virtual.
